# Redis Client

Redis キャッシュサーバーとの接続を管理するパッケージです。  
フレームワーク層でのキャッシュ操作の実装を提供します。

## 主な機能

- Redis サーバーへの接続管理
- キャッシュ操作の実装
- パイプライン処理

## 特徴

- 設定の外部化
- コネクションプールの最適化
- 分散キャッシュの管理
- 高可用性の確保

## 実装内容

- Redis 接続設定
- キャッシュ操作のインターフェース
- 原則無期限のキャッシュ管理
- エラーハンドリング
- フォールバック処理

## キャッシュ設計

永続化先を正とする cache-aside 方式を採用します。キャッシュの TTL は原則として無期限です。

データを追加・更新・削除する場合は、先に永続化先へ反映し、成功後に関連する Redis キーを削除します。更新処理内ではキャッシュ値を直接書き換えません。次回の読み込みでキャッシュミスが発生した際に、永続化先から最新版を取得して Redis に保存します。永続化に失敗した場合は、既存の Redis キーを削除しません。

## 使用方法

このクライアントは、アダプターレイヤーのキャッシュゲートウェイによって使用され、高速なデータアクセスを実現します。  
Clean Architecture の原則に従い、このパッケージの実装の詳細は上位レイヤーから隠蔽されています。
